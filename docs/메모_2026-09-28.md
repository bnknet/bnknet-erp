## A. 쿠팡 수량 미인식 수정 (PR #336, 배포 완료)
- 증상: 쿠팡 "위바이옴 두뇌엔 닥터 PS 맥스플러스 30포, N개, 60g" 주문이 1/2/3/5개 모두 **수량 1**로 변환됨.
- 원인: 수량 인식이 이름이 "N개/박스/세트"로 **끝나는** 경우만 지원 — 이 상품은 수량 뒤에 용량(60g)이 한 번 더 붙는 표기라 미인식(수집옵션에도 수량 정보 없음).
- 수정: `TRAIL_QTY_SPEC_RE` 추가 — "N개(박스/세트), <용량>"(g·kg·ml·l·정·포·캡슐 등 꼬리) 패턴 인식. 수량 단위를 개/박스/세트로 한정해 "30포, 60g"류 포장 규격 오인 방지. 회귀 케이스 11종 검증 통과.
- 참고: main의 09-07 수정("N포" 수량 제외, 옵션 콜론 형식, 수량 경고 표시)과 충돌 → 방향이 같아 리베이스로 병합(nameHasQty에 SPEC 패턴 포함).
- **사후 처리(담당자)**: 잘못 들어간 오늘 위바이옴 건들은 조회/취소 탭에서 **삭제 → 파일 재업로드**(업로드는 주문번호 중복 스킵이라 삭제 없이 재업로드하면 안 고쳐짐. 삭제 시 재고 자동 복구).
