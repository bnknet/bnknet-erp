- **GitHub** = 코드(설계도) 보관소. 기능 수정 → PR → main 머지로 기록.
- **Vercel** = 실행 서버. GitHub 코드를 받아 bnknet-erp.vercel.app 운영(슬랙 봇 엔드포인트 포함). 환경변수(슬랙 토큰·Anthropic 키) 여기서 관리, 변경 시 Redeploy 필요.

- 문제 유형별 위치: 기능/화면 = 코드(GitHub→Vercel) · 숫자 = SQL(Supabase) · 키/토큰 = Vercel 환경변수.
