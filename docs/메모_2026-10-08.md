## B. "Failed to load chunk …" 오류 — 배포 직후 옛 화면 문제
- 증상(실장): 정산 파일 업로드 시 "파일 분석 실패: Failed to load chunk /_next/static/chunks/….js?dpl=…".
- 원인: 코드 버그 아님. 새 배포(A) 직후 열려 있던 매출현황 화면이 옛 버전이라, 지연 로딩되는 엑셀 파서 조각을 옛 주소로 요청 → 새 배포엔 없음. **새로고침이 해결책.**
- 보강(배포): `src/lib/staleChunk.ts`(ChunkLoadError 감지 → "새 버전 배포, 새로고침 후 재시도" 안내 + 확인 시 자동 새로고침). 적용 4곳: 매출현황 정산 파일 분석, 주문변환 파일 변환, 결재 세무 엑셀 내보내기·품목 엑셀 읽기.
- 검증: tsc·build 통과(OneDrive가 `.next/static/<옛 빌드ID>` 잠가 EPERM 1회 → 폴더 삭제 후 재빌드).
