## B. "Failed to load chunk …" 오류 — 배포 직후 옛 화면 문제
- 증상(실장): 정산 파일 업로드 시 "파일 분석 실패: Failed to load chunk /_next/static/chunks/….js?dpl=…".

- 요청(실장): 지출결의서·매입품의서(카드구매)를 PDF와 엑셀로 한 번에 내려받아 세무사에게 전달.
- 기존: '세무용 엑셀'·'승인건 전체 PDF' 버튼이 있었으나 **기간·사업자 필터 없이 전체**를 내보냈음(3분기만 344건이라 전체는 부적합).

  - 분기 버튼(직전 2개 분기 + 이번 분기, 기본 = 직전 분기) + 시작~종료 직접 입력 + 사업자 선택(전체/개별). 기준일 = 지출일(없으면 발의일).
  - **엑셀 + PDF 한번에**: 같은 데이터·같은 정렬로 엑셀 다운로드 + PDF 인쇄창(브라우저 'PDF로 저장'). 엑셀만 / PDF만 버튼도 유지.
  - 엑셀: '요약' 시트(기간·사업자·문서종류별 건수·금액·취소문서) + 품목 시트(문서No·지출일·발의일·사업자·문서종류·거래처·계정과목·결제카드·결제예정일·월일·품목·수량·금액·판관비항목·비고·취소여부·첨부파일명·첨부URL). 파일명 `세무제출_기간[_사업자].xlsx`.
  - PDF: 표지(요약표) + 문서별 페이지(No. n/N, 양식, 품목, 카드, 영수자) + 이미지 증빙 inline, 파일 첨부(xls·pdf)는 파일명 표시. 문서No = 엑셀 문서No.
  - 팝업은 클릭 직후 열어 차단 방지, 품목은 100건씩 조회(긴 URL 누락 방지).
