## A. 영업이익 탭 — 결재 자동연동 판관비 품목별 제외 체크박스
- 요청(실장): 지출결의서 판관비 태깅이 영업이익 탭에 자동 합산되는데, 택배비처럼 이미 공헌이익에서 차감된 비용은 이중 차감. 건건이 결재를 고칠 수 없으니 세부내역에서 체크 해제하면 계산에서 빠지게.
- 데이터 확인: 매월 10일경 "N월 택배운임" 결재가 운반비로 태깅됨 — 9월 BNKNET 22,109,277 / IX글로벌 4,767,000 / 더블아이 2,171,600 / SJ글로벌 725,400, 8월 BNKNET 18,432,900 / 더블아이 1,772,900 / IX글로벌(물류·보관비) 1,194,000. 전부 공헌이익의 건당 택배 실운임과 중복.
- 구현:
  - `db/approval_item_opex_excluded.sql` — `approval_items.opex_excluded boolean default false` 추가.
  - `src/app/sales/OpexTab.tsx` — 항목을 펼치면 결재 품목마다 체크박스(체크=포함, 해제=제외). 해제 시 회색 취소선 + "제외" 배지, 항목 요약에 "계산 제외 N건 · 금액" 표시. 판관비 합계·영업이익·전사 롤업 모두 제외분 빼고 계산. 저장은 품목 PATCH(응답 검증, 실패 시 화면 되돌리고 알림). 결재 문서 자체는 변경 없음, 다시 체크하면 복원.
  - `src/app/api/assistant/route.ts` — 슬랙봇/챗봇 `profit_summary`도 같은 기준으로 제외(숫자 일관성).
  - SQL 미적용 DB에서도 기존처럼 전부 포함해 정상 표시(폴백 조회). 체크박스를 누르면 SQL 실행 안내.
- 검증: `npx tsc --noEmit`, `npm run build` 통과.

## B. 카드 결제 캘린더 — 선결제 납부분 '결제완료' 표시 + 나갈 금액에서 제외
- 문의(실장): 09-21 결제 예정 방성훈 현대카드를 담당자가 오늘 선결제 처리했는데 캘린더에서 차감돼 보이지 않음.
- 데이터 확인: 선결제는 정상 저장(강웅구 09-21 08:36, 48건 24,001,652원, 품목 prepaid_date=09-21). 기존 설계는 선결제액을 '선결제한 날 나간 돈(+)'으로 다시 더해서, 선결제일=결제예정일이면 그날 합계가 그대로였음. 한도현황에는 정상 반영(잔여 936,545 → 24,938,197).
- 결정(실장): 이미 납부한 돈은 "나갈 금액 0"이 맞음 → 결제완료로 표시.
- 구현(`src/app/cards/CardsContent.tsx`): 선결제일이 오늘까지 지난 부분선결제 이벤트에 `paid` 표시 → 구분 '결제완료'(회색 배지, 금액 취소선), 일별 합계·월 결제 예정 합계·기간 조회 합계·카드별 월 합계에서 0으로 취급. 달력 칸에 "✓ 결제완료 금액", 월 합계 카드에 "선결제로 이미 납부한 N원은 제외" 안내, 엑셀/보기 구분은 '결제완료(선결제)'. 선결제일이 미래면 기존처럼 그날 나갈 금액으로 표시. 한도 계산·독립 선결제 결재(is_card_payment) 로직은 변경 없음.
